# Dogfood: Retron and Retroposon Concepts

## Session Context

Newbie persona exploring the concept of retrons and their relationship
to retroposons/retrotransposons. Goal: understand what retrons are,
how they relate to other retroelements, and what the current research
landscape looks like. Starting with near-zero domain knowledge.

The `info` command was newly available in this session (implemented
after AD-8 from the cytidine deaminase session). FTS/vector search
still unavailable.

## Friction Log

### F1: ILIKE '%retron%' matches retronasal (word boundary issue)

```
FRICTION: Wanted to find papers about retrons
COMMAND: quarry sql "... WHERE title ILIKE '%retron%'"
OUTPUT:  15 results including "retronasal odor perception",
         "retronecine alkaloid biosynthesis"
PROBLEM: ILIKE has no word boundary awareness. Short terms like
         "retron" are substrings of many unrelated words.
WANTED:  Word-boundary-aware search: `quarry search "retron"` with
         tokenization, or sql helper like `title_contains('retron')`
         that wraps PG word boundary regex.
```

### F2: PG regex ~90s for word boundary search

```
FRICTION: Tried to fix F1 with regex word boundaries
COMMAND: quarry sql "... WHERE title ~ '\\mretron\\M'"
OUTPUT:  Correct 8 results, but took ~90 seconds
PROBLEM: PG regex on unindexed text column is full table scan.
         90s is unacceptable for interactive use. A newbie would
         have given up or assumed the tool is broken.
WANTED:  FTS with proper tokenization (solves both boundary and
         performance). Or at minimum, a GIN trigram index on title.
```

### F3: No MeSH term exposure for concept navigation

```
FRICTION: After finding retron papers, wanted to understand the
         ontological neighborhood (what category does "retron" fall
         under in the biomedical ontology?)
COMMAND: (no command available)
OUTPUT:  N/A
PROBLEM: MeSH terms are in the database but not exposed in any
         command. A newbie exploring "retron" would benefit from
         seeing that it falls under "Retroelements" > "DNA Transposable
         Elements" in MeSH, which immediately suggests related concepts.
WANTED:  `quarry mesh retron` or `quarry info W3096234081 --mesh`
         showing MeSH tree with navigable hierarchy. This became AD-9.
```

## Additional Observations

### Surprises (positive)

- The `info` command (new in this session) was immediately useful.
  It eliminated the sql-for-metadata pattern seen in S1. Three `info`
  calls replaced what would have been 3 sql queries + schema knowledge.
- `bridge` between defense retron (W3096234081) and engineering retron
  (W2051541780) correctly identified reverse transcriptase as the
  connecting concept. This is a non-obvious insight for a newbie.

### Dead ends

- `ILIKE '%retron%'` (CMD 1) was a dead end due to false positives.
  The workaround (PG regex) was too slow.

### Missing commands

- `mesh <term>`: MeSH hierarchy navigation. Seeing where "retron"
  sits in the ontology tree would accelerate concept understanding
  for newbies. This motivated AD-9.
- `search` (FTS): would have eliminated CMDs 1-2 entirely.

### Workflow suggestions

- **Newbie workflow should be**: `search "retron"` -> pick top hit ->
  `info W...` -> `expand W...` -> pick interesting neighbor ->
  `bridge W1 W2`. Currently the first step (search) is broken,
  forcing sql workarounds.
- `info` output could include a "Related concepts (MeSH)" section
  to guide exploration without requiring a separate `mesh` command.

## Research Findings

### Two Axes of Retron Research

| Axis | Seed Paper | Key Concept |
|------|-----------|-------------|
| Defense | W3096234081 (Millman et al. 2020) | Retrons as bacterial anti-phage defense systems (abortive infection) |
| Engineering | W2051541780 (Shipman et al. 2017) | Retrons as DNA recording/writing tools (SCRIBE, prime editing components) |

### Bridge Discovery: RT Diversity as Upper-Level Concept

The bridge between retron (W3096234081) and retrotransposon literature
revealed **reverse transcriptase (RT) diversity** as the unifying
concept. W916359970 (Beauregard et al.) provides the framework:

```
Reverse Transcriptase (RT) superfamily
  +-- Group II introns (self-splicing, mobile)
  +-- Retrons (bacterial, defense + engineering)
  +-- Retrotransposons (eukaryotic, LTR/non-LTR)
  +-- Retroviruses (viral, integrating)
  +-- Telomerase (chromosome maintenance)
```

This hierarchy was not obvious from the retron literature alone.
The bridge command surfaced it by finding papers that cite both
retron-specific and retrotransposon-specific works.

### Design Decision Triggered
